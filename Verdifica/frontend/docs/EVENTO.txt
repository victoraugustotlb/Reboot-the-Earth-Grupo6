RASTRO FLORESTAL — APRESENTAÇÃO EM OUTRO NOTEBOOK

PACOTE
Leve rastro-florestal-github.zip em um pendrive e mantenha uma segunda cópia.
O ZIP contém código, imagens locais, documentação e contextos das equipes.
Não contém Node.js, node_modules, certificados privados ou registros deste navegador.

ANTES DO EVENTO
1. Confirme o sistema do notebook e a presença do Node.js 22/24 com npm.
2. Confirme internet para instalar as dependências pela primeira vez.
3. Confirme que será permitido instalar o certificado local nos celulares de teste.
4. Confirme uma rede que permita comunicação entre notebook e celular.
   Wi-Fi de visitantes pode isolar dispositivos. Se permitido pela organização,
   teste uma rede própria/hotspot e use o IP informado pelo programa.

NO NOTEBOOK DO EVENTO — POWERSHELL/WINDOWS
1. Extraia o ZIP para uma pasta local.
2. Abra o terminal nessa pasta (a que contém package.json).
3. Confira: node --version
4. Instale: npm.cmd install
5. Teste: npm.cmd test
6. Inicie no computador: npm.cmd run dev
7. Abra: http://127.0.0.1:5173/

PARA USAR O CELULAR
1. Encerre o servidor do passo anterior com Ctrl+C, se não for usá-lo.
2. Execute: npm.cmd run mobile:https
3. Copie os endereços EXATOS mostrados nesse notebook.
   O IP 192.168.1.3 deste computador não deve ser presumido no evento.
4. Abra no celular a página HTTP da porta 5175 para instalar o certificado público.
5. O certificado será NOVO. Instale e habilite a confiança no novo certificado.
   O certificado deste computador não valida o notebook do evento.
6. Abra o endereço HTTPS da porta 8443 diretamente no Safari/Chrome.
7. Permita câmera e localização. Teste uma foto e salve um registro.
8. Mantenha terminal e notebook ligados durante a apresentação.

NO IPHONE
Ajustes > Geral > VPN e Gerenciamento de Dispositivo: instale o perfil recebido.
Ajustes > Geral > Sobre > Ajustes de Confiança de Certificados:
habilite a confiança na autoridade do notebook do evento.
Se já houver certificado com o mesmo nome, confira a impressão SHA-256
mostrada no terminal e na página de preparação para identificar o correto.
Não ignore alertas de conexão: confira a confiança, o endereço e a data.

TESTE DA APRESENTAÇÃO
- Abra o app em uma aba NORMAL, não privada.
- Crie um registro com produtor e espécie.
- Tire foto antes e salve.
- Abra o registro, tire foto depois e consulte o histórico.
- Teste o modo demonstração para comparar Local A e Local B, identificados como simulados.
- Atualize um registro já salvo e confira se fotos e metadados reaparecem.
- Teste até três tentativas em uma etapa e confira o bloqueio de uma quarta.

DADOS
Registros não estão no ZIP ou no servidor: ficam no navegador que os criou.
Outro aparelho/navegador/protocolo/IP/porta usa outro armazenamento.
Crie dados de apresentação no aparelho e endereço que serão usados no evento.
Não atualize uma página com rascunho ainda não salvo.

ALTERNATIVA PARA A DEMONSTRAÇÃO
Se a rede bloquear comunicação ou a instalação de certificados não for permitida,
apresente no navegador do notebook em http://127.0.0.1:5173/ com câmera disponível.
O GPS do notebook pode ser impreciso; use coordenadas de demonstração identificadas.
Depois da instalação das dependências, a interface não precisa de internet para carregar.
A obtenção da posição depende do dispositivo e dos serviços disponíveis.

AJUDA
Guia completo: docs/HTTPS-LOCAL.md dentro do projeto.
Diagnóstico: /diagnostico.html no mesmo endereço HTTPS do aplicativo.
Erro npm.ps1: use npm.cmd, sem alterar a política de execução do Windows.
Porta em uso: encerre a outra instância no terminal que a iniciou.
Não copie nem publique arquivos .key ou a pasta .local-https deste computador.
